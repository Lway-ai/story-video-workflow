# 写小说简报模板

> 用途：交给小说模型（或小说作者）之前，先把事实骨架、禁写清单、小说要求写死。
> 填好这份简报，再调模型。简报本身不进成片，但它是全片事实的唯一依据。
> 方括号 [ ] 内为待填项；“示例”行是格式示例，填自己的内容时删掉。

## 人名处理

- 所有人物名字一律用化名，不用真实姓名。
- 主角化名：[主角化名，如沈夏]；姐姐 / 家属化名：[如沈秋]；
  其他真人（救援队员、民警、民宿主人等）也都用化名。
- 时间、地点、衣着、事件经过仍按真实报道写，只有名字化名。

## 已确认的真实骨架

> 每条写明来源（媒体名 + 日期，或救援队转述 / 官方公告）。没有来源的事实不要写进来。

- 主角：[年龄、身份、籍贯、独自徒步、身高体重等报道确认项]；失联时 [上衣颜色、下装颜色]。
- [日期] 从 [出发地] 出发，[日期] 抵达 [目的地]，已订 [日期] 返程票，[原计划]。
- [日期时间] 左右独自从 [地点] 出发，往 [方向]，进入未开发未开放区域。
- [日期时间] 群消息：“[消息原文]”。
- [日期时间] 最后消息：“[消息原文]”，此后失联。
- [日期] 救援队接家属求助开始搜救，当天 [天气] 被迫下撤；[日期] 天气恶劣无法上山，仅无人机搜索，同日 [预警级别] 预警。
- [日期] 救援队接 [部门] 指令，依据警方提供的手机信号最后消失坐标确定搜救区域；[日期时间] 携 [装备] 出发，[时间] 在 [地点] 附近找到，[衣物与出发时一致、旁边有一部手机等确认项]；后续移交警方和消防。[时间] 左右家属称“[原话]”，[日期] 救援队对外确认。
- 参与：[救援队 A、救援队 B、消防、警方、应急管理部门]。
- 事前禁令：[日期] 当地政府公告禁止进入未开发未开放区域，点名 [地点 A、地点 B]，
  擅自进入需救援者承担救援费用、风险自负；同年该区域已有 [几起迷路救援]。

## 必须纠正 / 不能用的

- 地名是“[正确写法]”，不是“[常见错写]”。
- “[地点 X]”只是救援队推测方向，不是证实主角去了那里，也不是发现地。
- [其他线路 / 地点] 是禁令线路，不是主角的实际路线。
- 死因权威措辞始终是“[疑似滑坠 / 疑似坠崖等原文措辞]”，无警方通报、尸检或法医鉴定。

## 绝不能虚构为事实的

精确路线、坠落过程与高度、确切死亡时间与医学死因、遗体姿态 / 伤情等细节、
完整装备清单、家属报警具体时刻与对话、家庭背景、搜救犬 / 热成像仪等未证实手段、
无记录的追偿 / 处罚、[其他本案特有的禁写项]。

## 小说要求

- 中文小说，[八] 章，结构：[片头 / 出发地 / 村镇 / 遇险日 / 搜救日……/ 片尾]，
  可按需调整章名。
- 细节非常详细：人物外貌衣着、环境、天气、动作、物品、时间、声音、气味都要写具体，写满。
- 以已确认骨架为准写情节，内心活动和未证实的生活细节要写成明确的虚构演绎，
  不得写成“据报道”“警方称”。
- 不拍 / 不写精确路线、坠落过程、死亡时间、遗体细节；发现章只写无人机屏幕上的
  “一小块颜色”和雨衣覆盖，之后只写衣物。
- 目标是能直接拆成约 63 镜、每镜 9 秒的分镜表。

## 开头要求

- 开头用一句旁白先介绍整个故事——谁、什么时候、在哪里遇难、经过什么事件、
  永远留在那里；说完这一句，再从头讲起。不是闪前场景，而是一句交代前提的旁白。
- 这句措辞等小说写完后按新稿定，放在分镜表第一镜（T001）。

## 底线（全片通用，写进分镜表表头）

- 不拍精确路线、坠落过程、死亡时间、遗体细节。
- 消息、清单、草稿只用旁白转述，画面绝不出现文字。
- 无人机画面只拍灰屏和一小块颜色，不做假画面；发现段只拍衣物和雨衣覆盖远景。
